## Cómo se aprende

Cada laboratorio combina conceptos explicados desde cero, ejemplos ejecutables, ejercicios, depuración, retos y comprobaciones. Los laboratorios avanzan desde programas de consola hacia la aplicación **AgroDiversa**, un explorador de información agrícola de Colombia.

**No se requiere experiencia previa en programación** para iniciar el primer laboratorio. Este repositorio contiene la ruta de aprendizaje; el producto final tendrá su propio repositorio.

## Entregas y seguimiento de la ruta

Cada persona que desarrolla los ejercicios utiliza **un solo repositorio individual acumulativo** para guardar sus implementaciones. Este repositorio de guías no es el repositorio de entrega de cada participante. La aplicación AgroDiversa completa también tendrá un repositorio independiente.

Estructura sugerida para el repositorio individual:

```text
agrodiversa-learning/
├── README.md
├── lab-01/
│   └── dart_lab_01/
├── lab-02/
│   └── dart_lab_02/
├── lab-03/
│   └── dart_lab_03/
├── lab-04/
│   └── dart_lab_04/
└── lab-05/
    └── dart_lab_05/
```

Cada nuevo laboratorio **conserva los anteriores**, incorpora funcionalidades y deja commits significativos que permitan comprender su evolución, sin un número mínimo artificial. Tras completar cada práctica, el **README principal del repositorio individual** debe actualizarse con su estado, instrucciones de ejecución y principales cambios.

**Cada laboratorio requiere dos evidencias:** el enlace al repositorio individual y un **informe PDF adjunto**. El PDF documenta las funcionalidades, decisiones técnicas, casos de prueba, evolución mediante GitHub y las respuestas argumentadas a **cinco preguntas de análisis** incluidas en cada guía. Las preguntas de repaso son opcionales y distintas de las preguntas evaluables.

El desarrollo práctico conserva la duración de **4,5 horas por laboratorio**; la elaboración del PDF es una actividad de entrega posterior, no un reemplazo de las prácticas. Estas indicaciones son neutrales y pueden utilizarse en distintos entornos educativos.

## Organización prevista

- **Dart**: fundamentos, decisiones, funciones, colecciones, programación orientada a objetos, manejo de datos y asincronía.
- **Flutter**: interfaces, estado, navegación, integración de datos y pruebas.
- **Proyecto integrador**: funcionalidades de AgroDiversa incorporadas gradualmente.

Las siguientes guías se enlazarán aquí a medida que estén publicadas. Los contenidos y ejercicios son independientes de una institución educativa.
