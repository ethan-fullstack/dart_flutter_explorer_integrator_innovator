## Cómo se aprende

Cada laboratorio combina conceptos explicados desde cero, ejemplos ejecutables, ejercicios, depuración, retos y comprobaciones. Los laboratorios avanzan desde programas de consola hacia la aplicación **AgroDiversa**, un explorador de información agrícola de Colombia.

**No se requiere experiencia previa en programación** para iniciar el primer laboratorio. Este repositorio contiene la ruta de aprendizaje; el producto final tendrá su propio repositorio.

## Organización prevista

- **Dart**: fundamentos, decisiones, funciones, colecciones, programación orientada a objetos, manejo de datos y asincronía.
- **Flutter**: interfaces, estado, navegación, integración de datos y pruebas.
- **Proyecto integrador**: funcionalidades de AgroDiversa incorporadas gradualmente.

Las siguientes guías se enlazarán aquí a medida que estén publicadas. Los contenidos y ejercicios son independientes de una institución educativa.
